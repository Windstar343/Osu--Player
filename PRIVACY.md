# Privacy

This source package contains code, build instructions, dependency lockfiles, and application artwork. It does not include a developer's music, osu! database, playlists, listening history, Windows configuration, credentials, local development logs, or local executables.

The application discovers library folders at runtime on each user's own PC. Source choices, favorites, playlists, playback sessions, volume, and settings are kept in that installation's local storage. They are not part of this repository. Playlist backups may contain local song paths; review a backup before sharing it.

Discord sharing is optional and off by default. No developer-specific Discord Application ID is included. A maintainer can supply a public ID when building. Local artwork is not uploaded by this integration. Public beatmap cover URLs may be displayed when sharing is enabled.

The application does not include analytics. Opening a beatmap page opens the osu! website. Dependency installation and GitHub builds contact their package registries and GitHub.

Build downloadable executables using the manually started Windows workflow on GitHub. Local debug builds can embed source paths and should not be uploaded as releases.
